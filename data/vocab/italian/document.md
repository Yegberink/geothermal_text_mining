# Italian Language Resources

This folder contains Italian-specific vocabulary and normalization resources used by the workflow.

- `date_locale.yaml`: Italian month and weekday names for Lexis-style date conversion.
- `geothermal_patterns.txt`: Regex patterns used for preprocessing geo-hit counts.
- `location_province_overrides.csv`: Optional manual mapping from ambiguous extracted locations to Italian province/region names. It is currently empty.
- `keywords_topics.csv`: Italian frame/category keyword vocabulary used by the paragraph filter and sentence/category classifier.
